# Incident: espresso machine went down

On 2026-05-10 the espresso machine died mid-morning during the rush. No shots at
all for about an hour.

Root cause: a tripped breaker. The grinder and machine were on the same circuit and
the extra load from a second grinder we had just added overloaded it.

Fix: moved the second grinder to a different circuit and reset the breaker. Booked
an electrician to add a dedicated line so it does not happen again.
